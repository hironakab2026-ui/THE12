# THE 12 会員ページ（デモ）

**公開URL**: https://hironakab2026-ui.github.io/THE12/member/

紹介ページ（[`../intro/`](../intro/)）の「無料ではじめる」から開く、会員ページのデモ。
「実現したらこう動く」を見せるためのもので、料金・ポイント処理はない。要件は「The 12 会員ページ 要件定義書」を参照。

## 画面

| URL（# のあと） | 画面 | 動き |
| --- | --- | --- |
| （初回のみ） | 初回登録 → 使い方紹介 →「はじめまして。そして、おかえりなさい。」 | ユーザー名・アイコン・推し球団・性別/年齢（任意）を登録。ユーザー名の重複は不可 |
| `#/` | ホーム | 流れる帯（広告・投票速報・試合経過）、2×2 のコンテンツ、入会特典 |
| `#/join` | 参加する | 総選挙の途中経過・投票（残り回数・履歴）、ファン首脳会議 |
| `#/watch` | 見る | おすすめ・動画検索・最新（動画は準備中） |
| `#/collect` | 集める | ガチャ（PICK UP／NORMAL、1回／10回）、右下の辞書アイコン |
| `#/collection` | コレクション | ★のカードが先頭、その他は引いた順 |
| `#/taste` | 味わう | グルメ投票・Uber Eats で注文（準備中） |

## 動かす

```bash
cd member
npm install
npm run dev
```

ブラウザで http://localhost:5174/ を開く。画像は紹介ページの `intro/public/` を共有している。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発用サーバーを起動 |
| `npm run build` | 型チェック＋本番用ファイルを `member/dist/` に出力 |
| `npm run icons` | 「イメージ　アイコン」から会員アイコン（`intro/public/assets/icons/`）を作り直す |

## データの記録（Firebase）

`src/config.ts` の `FIREBASE_CONFIG` が `null` のあいだは **お試しモード** で、記録はその端末のブラウザ内だけに保存される（他の人の投票は得票数に入らない）。
Firebase を設定すると、登録・投票・ガチャの記録が Firestore に保存され、全員で共有される。

### 設定手順（初回のみ）

1. [Firebase コンソール](https://console.firebase.google.com/) で「プロジェクトを追加」（Google アナリティクスは不要）
2. 「構築 → Firestore Database → データベースを作成」。ロケーションは `asia-northeast1（東京）`、**本番環境モード** で作成
3. 「Firestore Database → ルール」に [`firestore.rules`](firestore.rules) の中身を貼り付けて「公開」
4. 「プロジェクトの設定（歯車）→ マイアプリ → ウェブ（`</>`）」でアプリを登録し、表示される `firebaseConfig` の値を `src/config.ts` の `FIREBASE_CONFIG` に貼る
5. `main` に push すると自動で公開される

Firebase のウェブ用設定値は公開して問題ない値（秘密の鍵ではない）。書き込める範囲は `firestore.rules` で制限している。

### 記録の中身（Firestore）

| コレクション | 内容 |
| --- | --- |
| `users/{ユーザー名}` | アイコン・推し球団・★のカード・登録日時 |
| `users/{ユーザー名}/votes` | 投票履歴（1票1件） |
| `users/{ユーザー名}/cards` | ガチャで引いたカード（1枚1件） |
| `private/{ユーザー名}` | 性別・年代（画面には出さない。Firebase コンソールで確認） |
| `tally/{候補ID}` | 得票数（途中経過には、デモ用の初期票に実際の票を足して表示） |

デモの前後で記録を消すときは、Firebase コンソールで各コレクションを削除する。
