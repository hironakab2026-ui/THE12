# THE 12 紹介ページ スタイルガイド（v0.1 / 2026-11-15）

企画書「15班グループワーク」11/15タブを基準に、紹介ページが **「The 12」をPRするために必要なこと** を先に確定させる。
既存コンセプトページ（黒×金・12人のシルエット）を土台とし、下記の調整を加える。

---

## 1. 前提：このページの役割

| 項目 | 企画書（11/15）の内容 | ページへの落とし込み |
| --- | --- | --- |
| 位置づけ | 広報②（Web・SNS広告）の着地点。「The 12を認知させる → 入会させる」 | **ページのゴールは「無料入会」1つ**。全セクションが入会CTAへ流れる構成にする |
| メインターゲット | 30代男性の「出戻り予備軍」（愛着はあるが、ライフステージの変化で観戦習慣を失った層） | 「知らない人向けの説明」ではなく **「おかえり」と迎える語り口** |
| インサイト | 息抜きの趣味が欲しい／家族への体裁が保てる／孤独が解消できる | 「家族と楽しめる」「仲間とつながる」「スキマ時間でいい」を視覚的に示す |
| 出戻りの障壁 | ①戻るフックがない ②いきなり特定球団を推すのは難しい ③自分時間がない | ①ヒーローのコピー ②「球団を決めなくていい」 ③「数分から楽しめる」 を明示 |
| 流入経路 | デジタル広告中心（SNS） | **スマホ・縦スクロール前提**。1画面1メッセージ、常時表示の入会ボタン |
| コピー | 「試合を見るだけが楽しみ方じゃない。」「お父さんお帰りなさい、野球もあなたの帰りを待ってました。」 | ヒーロー＝おかえり（感情のフック）、直後＝試合を見るだけじゃない（The 12の価値） |

## 2. トーン＆マナー

**キーワード：「ナイターの灯り」— 懐かしさ × 温かさ × 特別感**

| 既存ページ | 調整後 | 理由 |
| --- | --- | --- |
| 黒×金のラグジュアリー、やや冷たく排他的 | 黒は「夜の球場」として残し、**照明の暖色（アンバー）** を足して温度を上げる | ターゲットの記憶にあるのは「夜、家族で食卓を囲んで見たナイター」。高級感より帰ってきたくなる温かさが必要 |
| 「PRO BASEBALL, REBORN」「野球は、○○だ。」 | 「おかえりなさい。野球も、あなたの帰りを待っていました。」 | 企画書のコピー案を採用。リブランディングより「迎え入れ」を前面に |
| 選手名鑑・施策説明中心 | **「自分の楽しみ方」が先**、仕組みの説明は後ろ | PRページなので、NPB側の論理（評価軸など）はABOUTへ下げる |
| 英字見出しが主役 | 英字は装飾（キッカー）、**日本語の短い一文が主役** | 30代の忙しい読者がスクロールしながら1秒で理解できること |

文体：です・ます調。1文は40字以内を目安。専門用語（デジタルID、グレード制）は初出で言い換える。

## 3. カラー

既存トークンを維持しつつ、暖色とステータス色を追加（`src/styles/tokens.css`）。

| トークン | 値 | 用途 |
| --- | --- | --- |
| `--bg` | `#060606` | 夜の球場。ページ地 |
| `--bg2` / `--panel` | `#0f0e0c` / `#15130f` | カード、帯（わずかに暖色寄りへ変更） |
| `--ink` | `#f4efe4` | 本文（生成りの白＝照明に照らされた紙） |
| `--ink-dim` / `--ink-mute` | `#c2baa9` / `#8a8374` | 補足文／注記（コントラスト比 4.5:1 以上を確保） |
| `--gold` / `--gold-soft` | `#c8a24d` / `#e6c87e` | ブランド色。ロゴ・番号・罫線・キッカー |
| `--amber` | `#f0a848` | **新規**。ナイター照明。光の演出、強調の一語 |
| `--cta` / `--cta-ink` | `#e6c87e` / `#14110a` | **入会ボタン専用**の塗り。ページ内で塗りボタンはこれだけ |

ルール：
- 塗りボタン（primary）は **入会導線だけ** に使う。他は線ボタン（ghost）。視線が迷わないようにする。
- 4つの楽しみ方（選ぶ／参加する／見る／味わう）は色分けしない。ゴールドの番号と動詞ラベルで区別し、ブランド色を薄めない。
- ダークモード固定（`color-scheme: dark`）。「夜の球場」がブランドそのものであるため。

## 5. ページ構成

1ページ構成。見出しは項目名そのまま（キャッチコピー・番号はつけない）。メニュー・フッターもこの5項目。

| 項目 | 内容 |
| --- | --- |
| HOME | THE 12ロゴ（`public/assets/logo.webp`）→「おかえりなさい」→ 12人＋観客席 → 入会ボタン。スクロールせずに1画面に収める。開いたときに上の順で浮かび上がる（選手は中央から外側へ） |
| ABOUT THE 12 | 「プロ野球好きのすべての人が“ゼロから”作り上げるファンクラブ」＋説明文＋5つのポイント |
| CONTENTS | 選ぶ／参加する／見る／味わう の2×2ボックス。各コンテンツは背景画像つき。2件あるボックスはカーソルを乗せた方が広がる。詳細ページはタイトル部分の背景に同じ画像 |
| MEMBERSHIP | NORMAL（無料）／12+α（月300円・「もっと楽しみたい方へ」）＋今後のグレード |
| FAQ | よくある質問 |

最後に入会ボタンの帯（「あなたの“好き”を、ここから。」）。フッターは THE 12 と5項目だけの小さな帯。
スクロールすると各項目がなめらかに浮かび上がる。モバイルでは画面下に入会ボタンを常時表示（ヒーロー通過後に出現）。

## 7. アクセシビリティ・品質基準

- タップ領域は最小44px。本文コントラスト 4.5:1 以上。
- `prefers-reduced-motion` でアニメーションを停止。
- 画像は使う場合必ず `alt` を記述。装飾SVGは `aria-hidden`。
- 幅360pxで横スクロールが出ないこと。
